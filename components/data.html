Data display

Components for numbers. Tables align figures on tabular digits, stat cards put a key number up front with its trend, and every series swatch is a small hexagon.

Table

Wrap tables in .vc-table-wrap so they scroll sideways on small screens instead of breaking the layout. While a wrapper scrolls, vici.js makes it focusable and names it after the table's caption, so keyboard users can scroll it too. Right-align numeric columns with .vc-num. Add data-vc-sortable and a .vc-table__sort button in each sortable header, and vici.js sorts the rows and sets aria-sort. Cells can carry a data-value for exact sorting.

Row selection and bulk actions

Put a checkbox in the first cell of each row. The row tint follows the checkbox, so the state is visible and announced. With data-vc-select="#toolbar-id" on the table, vici.js keeps a select-all checkbox in the header (checked, mixed or empty) and a .vc-table-toolbar with the count in sync. The toolbar stays hidden while nothing is selected. Don't rely on aria-selected in a plain table: it only has a meaning in a grid widget.

Chart frame

.vc-chart is a <figure> with a title, a subtitle, the chart, a legend and a source line. Vici doesn't include a charting library. Draw with SVG, D3, Observable Plot or Vega-Lite and use the --vc-data-* tokens for colour. Recommended chart types and the palettes are on Data visualisation.

Anatomy

The frame around a chart you draw yourself. Give the SVG a width and height (the size you drew it at) and wrap it in .vc-chart__plot: the chart keeps that size, so its 11 px labels stay 11 px, and in narrower columns the plot scrolls sideways (with vici.js, it then also becomes focusable, so keyboards can scroll it). Label bars directly where you can, and add a .vc-legend only when there are several series.
