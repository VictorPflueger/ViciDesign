Components

Forms

Form controls are native elements with a Vici skin, so validation, autofill, keyboard support and mobile keyboards all work as usual. The hexagon shows up where other systems draw circles: in the radio, the switch knob, the slider thumb and the rating cells.

Field

A field stacks a label, the control, and optional help or error text. Connect the help text with aria-describedby.

We only use it to send the report.

€

Use letters and digits only, without spaces.

<div class="vc-field">
  <label class="vc-label" for="f-email">Work email <span class="vc-label__required" aria-hidden="true">*</span></label>
  <input class="vc-input" id="f-email" type="email" placeholder="name@company.com" required aria-describedby="f-email-help" autocomplete="email">
  <p class="vc-help" id="f-email-help">We only use it to send the report.</p>
</div>

Select

A native <select> with a Vici chevron. Use it for six or more options. For fewer, radios or a segmented control show all choices at once.

HTML
<div class="vc-field">
  <label class="vc-label" for="f-region">Region</label>
  <select class="vc-select" id="f-region">
    <option>DACH</option>
    <option selected>Nordics</option>
    <option>Benelux</option>
    <option>Southern Europe</option>
    <option>Central &amp; Eastern Europe</option>
    <option>United Kingdom &amp; Ireland</option>
  </select>
</div>

Combobox

For “type or choose”, combine a text input with a native <datalist>. The browser handles filtering and keyboard selection.

HTML
<div class="vc-field">
  <label class="vc-label" for="f-model">Model</label>
  <input class="vc-input" id="f-model" list="f-model-list" placeholder="Start typing…">
  <datalist id="f-model-list">
    <option value="Forecasting — gradient boosting"></option>
    <option value="Forecasting — temporal fusion transformer"></option>
    <option value="Classification — logistic regression"></option>
    <option value="Retrieval — hybrid search"></option>
  </datalist>
</div>

Checkbox

Checkboxes stay square: squares aren't circles. Group them in a <fieldset> with a <legend>. Add data-vc-indeterminate for a mixed parent state.

Data sources
HTML
<fieldset class="vc-fieldset">
  <legend>Data sources</legend>
  <label class="vc-checkbox"><input type="checkbox" data-vc-indeterminate> All sources</label>
  <label class="vc-checkbox"><input type="checkbox" checked> ERP purchase orders</label>
  <label class="vc-checkbox"><input type="checkbox"> Supplier contracts (PDF)</label>
  <label class="vc-checkbox"><input type="checkbox" disabled> Market data (licence needed)</label>
</fieldset>

Switch

A hex-capsule track with a hexagon knob. Use a switch for settings that apply immediately. Use a checkbox when the change only takes effect after the user submits the form. Add role="switch".

HTML
<div class="vc-stack vc-stack--sm">
  <label class="vc-switch"><input type="checkbox" role="switch" checked> Email digest</label>
  <label class="vc-switch"><input type="checkbox" role="switch"> Show AI suggestions</label>
  <label class="vc-switch"><input type="checkbox" role="switch" disabled> Beta features</label>
</div>

Chip

Chips are selectable filters in a hex capsule. Use toggle buttons with aria-pressed and a .vc-chip__check icon, or checkboxes inside a label, where the checkbox itself turns into the check mark. Selected chips get the accent fill and a check, so the state doesn't depend on colour.

HTML
<div class="vc-chip-group" role="group" aria-label="Filter by status">
  <button type="button" class="vc-chip" aria-pressed="true"><span class="vc-icon vc-icon--check vc-chip__check" aria-hidden="true"></span>Open</button>
  <button type="button" class="vc-chip" aria-pressed="false"><span class="vc-icon vc-icon--check vc-chip__check" aria-hidden="true"></span>In review</button>
  <button type="button" class="vc-chip" aria-pressed="false"><span class="vc-icon vc-icon--check vc-chip__check" aria-hidden="true"></span>Approved</button>
  <button type="button" class="vc-chip" aria-pressed="false" disabled><span class="vc-icon vc-icon--check vc-chip__check" aria-hidden="true"></span>Archived</button>
</div>

Rating

Five hexagon cells, filled in honey up to the chosen value. It's a group of native radios, so the arrow keys work. Hovering previews a value.
