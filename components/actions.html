Components

Actions

Buttons start things, links go places. Buttons are calm rectangles, and icon buttons are hexagon cells. A view should have one primary action.

Button

Use <button> for actions and <a class="vc-button"> only when it navigates. The primary button is filled with the base colour. In dark mode it turns into pastel blush with merlot text.

HTML
<button type="button" class="vc-button">Primary</button>
<button type="button" class="vc-button vc-button--secondary">Secondary</button>
<button type="button" class="vc-button vc-button--outline">Outline</button>
<button type="button" class="vc-button vc-button--ghost">Ghost</button>
<button type="button" class="vc-button vc-button--danger">Delete</button>

Sizes and icons

HTML
<button type="button" class="vc-button vc-button--sm"><span class="vc-icon vc-icon--plus" aria-hidden="true"></span>Small</button>
<button type="button" class="vc-button"><span class="vc-icon vc-icon--download" aria-hidden="true"></span>Medium</button>
<button type="button" class="vc-button vc-button--lg">Large <span class="vc-icon vc-icon--arrow-right" aria-hidden="true"></span></button>

States

HTML
<button type="button" class="vc-button" disabled>Disabled</button>
<button type="button" class="vc-button vc-button--secondary" aria-busy="true"><span class="vc-spinner" aria-hidden="true"></span>Saving…</button>
<button type="button" class="vc-button vc-button--outline vc-button--toggle" aria-pressed="true"><span class="vc-icon vc-icon--eye" aria-hidden="true"></span>Preview on</button>
<button type="button" class="vc-button vc-button--outline vc-button--toggle" aria-pressed="false">Toggle me</button>

A toggle button keeps its state in aria-pressed. With vici.js loaded, clicking flips it. A busy button gets aria-busy="true" and a spinner; keep its label meaningful (“Saving…”).

Full width and groups

HTML
<button type="button" class="vc-button vc-button--block">Continue to payment</button>
<div class="vc-button-group" role="group" aria-label="Time range">
  <button type="button" class="vc-button vc-button--outline">Day</button>
  <button type="button" class="vc-button vc-button--outline">Week</button>
  <button type="button" class="vc-button vc-button--outline">Month</button>
</div>
ClassEffect
.vc-buttonPrimary (accent fill), 40 px high
--secondary · --outline · --ghost · --dangerEmphasis variants
--sm · --lg32 px · 48 px
--blockFull width
--toggle + aria-pressedTwo-state button
.vc-button-groupJoins adjacent buttons

Icon button

An icon button is a hexagon cell. The element itself stays unclipped: ::before paints the cell and ::after draws the hexagonal focus ring. Always give it an aria-label.

HTML
<button type="button" class="vc-icon-button" aria-label="Search"><span class="vc-icon vc-icon--search" aria-hidden="true"></span></button>
<button type="button" class="vc-icon-button vc-icon-button--soft" aria-label="Edit"><span class="vc-icon vc-icon--edit" aria-hidden="true"></span></button>
<button type="button" class="vc-icon-button vc-icon-button--solid" aria-label="Add"><span class="vc-icon vc-icon--plus" aria-hidden="true"></span></button>
<button type="button" class="vc-icon-button vc-icon-button--outline" aria-label="Filter"><span class="vc-icon vc-icon--filter" aria-hidden="true"></span></button>
<button type="button" class="vc-icon-button vc-icon-button--sm" aria-label="Close"><span class="vc-icon vc-icon--close" aria-hidden="true"></span></button>
<button type="button" class="vc-icon-button vc-icon-button--lg vc-icon-button--soft" aria-label="Settings"><span class="vc-icon vc-icon--settings" aria-hidden="true"></span></button>
<button type="button" class="vc-icon-button vc-icon-button--floating" aria-label="New report"><span class="vc-icon vc-icon--plus" aria-hidden="true"></span></button>

Variants: default (ghost), --soft, --solid, --outline, --floating. Sizes: --sm, --lg. Pair icon-only buttons with a tooltip.

Link

Links in running text are underlined in merlot and need no class. Use .vc-link for standalone links such as “Read more”, and the external icon when a link leaves the site.

Read the contribution notes before you change a token.

View all reports WCAG overview at the W3C Quiet link

<p style="margin:0">Read the <a href="#link">contribution notes</a> before you change a token.</p>
<a class="vc-link" href="#link">View all reports <span class="vc-icon vc-icon--arrow-right" aria-hidden="true"></span></a>
<a class="vc-link" href="https://www.w3.org/WAI/standards-guidelines/wcag/">WCAG overview at the W3C <span class="vc-icon vc-icon--external" aria-hidden="true"></span></a>
<a class="vc-link vc-link--quiet" href="#link">Quiet link</a>

Segmented control

A segmented control picks one of two to five options that change a view. It's a radio group, so it needs no script and works with the arrow keys.

HTML
<div class="vc-segmented" role="radiogroup" aria-label="Chart type">
  <label><input type="radio" name="seg-chart" checked><span><span class="vc-icon vc-icon--chart-bar" aria-hidden="true"></span>Bars</span></label>
  <label><input type="radio" name="seg-chart"><span><span class="vc-icon vc-icon--chart-line" aria-hidden="true"></span>Lines</span></label>
  <label><input type="radio" name="seg-chart"><span><span class="vc-icon vc-icon--honeycomb" aria-hidden="true"></span>Waffle</span></label>
</div>
<div class="vc-segmented" role="radiogroup" aria-label="Period">
  <label><input type="radio" name="seg-period"><span>7 days</span></label>
  <label><input type="radio" name="seg-period" checked><span>30 days</span></label>
  <label><input type="radio" name="seg-period"><span>Year</span></label>
</div>

Use tabs instead when each option shows different content, and a select when there are more than five options.
