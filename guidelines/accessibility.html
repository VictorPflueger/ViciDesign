Guidelines

Accessibility

Vici aims at WCAG 2.2 level AA as the minimum. Some of it is enforced by the build: contrast, the colour-blindness spacing of chart colours, focus colours. The rest depends on how the components are used, and this page explains how.

What the system guarantees

  • Every semantic text pairing reaches at least 4.5:1 in both themes. Body text reaches 7:1 (AAA). See the contrast table.
  • Input borders, unchecked controls, focus rings and chart marks reach 3:1 against their surroundings.
  • The six categorical chart colours stay measurably apart under simulated protanopia, deuteranopia and tritanopia.
  • Every interactive component has a visible focus indicator: a 2 px ring with a 2 px gap, hexagonal on hexagon controls.
  • Native elements come first: <button>, <input>, <details>, <dialog> and popover bring keyboard support and semantics for free.
  • Animations stop when the user asks for reduced motion.

Focus

Focus appears for keyboard users only (:focus-visible), and always in --vc-focus: merlot 700 in light mode, blush in dark mode. Text inputs show it whenever they are focused, because typing needs to see where it goes.

<button class="vc-button">Rectangle</button>
<button type="button" class="vc-icon-button vc-icon-button--soft" aria-label="Settings"><span class="vc-icon vc-icon--settings" aria-hidden="true"></span></button>
<label class="vc-radio"><input type="radio" name="a11y-focus"> Hexagon ring</label>
<button type="button" class="vc-chip" aria-pressed="false">Capsule ring</button>

Semantics checklist

  • Set lang on <html> and keep one <h1> per page, with headings in order.
  • Give icon-only buttons an aria-label, and mark decorative icons with aria-hidden="true".
  • Connect every form control to a visible <label>. Connect help and error text with aria-describedby, and mark errors with aria-invalid="true".
  • Group related radios and checkboxes in a <fieldset> with a <legend>.
  • Use role="switch" on switch checkboxes so screen readers announce “on/off”.
  • Give progress bars and hex progress rings role="progressbar", aria-valuenow, aria-valuemin, aria-valuemax and a label.
  • Announce toasts in a live region. Vici.toast() creates one with aria-live="polite" and uses role="alert" for errors.
  • Charts need a text alternative: an aria-label that states the finding, plus the data as a table.

Contrast themes and text size

  • Windows contrast themes (forced colours) replace the palette with a few system colours and drop background colours. Vici repaints everything it draws with backgrounds, such as icons, hexagon rings, check marks, switches, ratings and focus rings, in system colours, so every control stays visible and operable.
  • Larger text: sizes are in rem, so controls and labels grow with the reader's font size setting. Checkboxes, radios and switches grow with it, and long labels wrap without overlapping.
  • Reflow: every page works at 320 px without horizontal scrolling. Wide tables and charts scroll inside their own frame.

Colour is never the only signal

Status always combines colour with an icon and words. Selected chips show a filled shape and a check. Trends pair sage or coral with an arrow. Rating cells change from outline to solid, not only from grey to honey.

Testing

  1. Navigate the page with the keyboard only. Can you reach, see and operate everything?
  2. Zoom to 200 % and narrow the window to 320 px. Nothing should overlap or need horizontal scrolling, apart from wide tables.
  3. Switch to the dark theme and turn on reduced motion.
  4. Run an automated checker (axe, Lighthouse) and a screen reader (NVDA or VoiceOver) on the critical flows.
  5. Run npm run check after changing tokens. It fails on contrast regressions.
