Guidelines

Iconography

Vici has its own set of 64 line icons. They are drawn on a 24 px grid with 1.75 px strokes and rounded joins, and they follow the hexagon rule: the search lens, a user's head, an eye's pupil, a clock face, the dots of “more” and the info and success badges are all hexagons, and the moon is a hexagonal crescent. Arrowheads and chevrons use the hexagon's 120° corner instead of the usual right angle, which gives the set its slightly pointed look.

Using icons

As a class (recommended)

Each icon is an SVG mask inside the stylesheet, so it needs no extra request, works across domains and takes the current text colour.

HTML
<span class="vc-icon vc-icon--search" aria-hidden="true"></span>
<span class="vc-icon vc-icon--sparkle vc-icon--lg vc-text-accent" aria-hidden="true"></span>
<span class="vc-icon vc-icon--chart-line vc-icon--xl" style="color: var(--vc-fjord-600)" aria-hidden="true"></span>
<button type="button" class="vc-button vc-button--secondary"><span class="vc-icon vc-icon--download" aria-hidden="true"></span>Export</button>

Sizes: --xs 14 px, --sm 16 px, default 20 px, --lg 24 px, --xl 32 px, or any value through --vc-icon-size.

From the sprite

<svg class="my-icon" width="24" height="24" aria-hidden="true">
  <use href="/dist/vici-icons.svg#vc-search"></use>
</svg>

Sprites only work from the same origin, so copy dist/vici-icons.svg into your site. The single SVG files are in src/icons/ for design tools and inline use.

Drawing new icons

  • 24 × 24 artboard, 2 px padding, stroke-width="1.75", round caps and joins, no fills except for small dots.
  • Draw round elements as hexagons. A flat-top hexagon with a circumradius of 9 replaces a full-size circle. Smaller dots are hexagons with a radius of 1.2–1.75.
  • Horizontal and vertical arrows and chevrons open at 120°: each wing leaves the tip at 60° to the shaft. Diagonal arrows (external link, trends) keep a right-angled head that sits on the grid.
  • Prefer sharp, chamfered corners over rounded ones; a corner that would be rounded is cut at 45° or 60°.
  • Keep the visual weight of a 16 px circle: if an icon looks lighter than its neighbours, enlarge it, don't thicken the strokes.
  • Save the file into src/icons/ with a lowercase, hyphenated name and run the build. The class, the sprite symbol and the gallery are generated.
  • Don't draw icons for other brands. A link to LinkedIn or GitHub uses the platform's own logo file, unchanged (see Profile links).

Accessibility

  • Decorative icons next to text get aria-hidden="true".
  • Icon-only buttons need an accessible name: aria-label="Search". Add a tooltip that shows the same text.
  • Don't use an icon as the only carrier of meaning in status messages. Pair it with words.
