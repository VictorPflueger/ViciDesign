Start

Getting started

Vici is plain CSS with an optional sprinkle of JavaScript. There is no framework, no build step and no package to install. Link one stylesheet and the components work in any HTML: a static website, a Streamlit custom component, a Jinja template or a React app.

1 · Link the stylesheet

Choose one of three sources. All of them serve the same files from dist/, and the fonts load from assets/fonts/ next to it.

From the CDN

jsDelivr serves files straight from the GitHub repository. Pin a release tag (for example @v1.0.0) for production work and use @main while you experiment.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/VictorPflueger/ViciDesign@v1.0.0/dist/vici.min.css">
<script src="https://cdn.jsdelivr.net/gh/VictorPflueger/ViciDesign@v1.0.0/dist/vici.js" defer></script>

From GitHub Pages

Once Pages is switched on for the repository, the documentation lives at victorpflueger.github.io/ViciDesign and the stylesheet sits at …/ViciDesign/dist/vici.min.css.

As a local copy

For offline prototypes, or anything that must not load from a third-party server, copy dist/ and assets/fonts/ into your project and keep their relative positions:

my-prototype/
├── index.html
└── vici/
    ├── dist/vici.min.css      ← link this
    ├── dist/vici.js
    └── assets/fonts/*.woff2   ← loaded by the stylesheet

No third-party font requests

The three typefaces are bundled as WOFF2 files and load from the same place as the stylesheet. Readers' IP addresses never reach a font CDN, which keeps the system easy to use on sites that need to comply with the GDPR.

2 · Start from a blank page

This is the smallest complete page. The inline script in <head> applies a saved theme before the first paint, so dark mode never flashes white.

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My prototype</title>
  <link rel="stylesheet" href="vici/dist/vici.min.css">
  <script>try{var t=localStorage.getItem('vc-theme');if(t==='light'||t==='dark')document.documentElement.setAttribute('data-theme',t)}catch(e){}</script>
  <script src="vici/dist/vici.js" defer></script>
</head>
<body>
  <main class="vc-container vc-section vc-stack">
    <h1>Hello, Vici</h1>
    <p class="vc-lead">Plain HTML already looks right.</p>
    <div class="vc-cluster">
      <button class="vc-button">Primary</button>
      <button class="vc-button vc-button--secondary">Secondary</button>
    </div>
  </main>
</body>
</html>

Ready-made pages for an app prototype, a dashboard and a personal landing page are on Starters.

3 · Use the components

Every component is a class prefixed with vc- and uses BEM-style parts and modifiers: .vc-card, .vc-card__title, .vc-card--elevated. The demos throughout these pages are live, and each one has its exact HTML under HTML, ready to copy.

VP AI draft 3
HTML
<button class="vc-button">Save changes</button>
<button class="vc-button vc-button--secondary">Preview</button>
<span class="vc-avatar vc-avatar--lilac">VP</span>
<span class="vc-tag vc-tag--feature"><span class="vc-icon vc-icon--sparkle" aria-hidden="true"></span>AI draft</span>
<span class="vc-badge">3</span>

Plain HTML gets sensible defaults

Headings, paragraphs, links, lists, tables, code and form controls are styled without classes, so quick prototypes look finished before you add a single class. Unordered lists get hexagon bullets.

4 · Know the files

FileWhat it is
dist/vici.css / vici.min.cssEverything: fonts, tokens, both themes, base styles, layout, components, icons, utilities.
dist/vici-tokens.cssOnly the CSS custom properties, for projects that bring their own components.
dist/vici.jsOptional behaviours: theme toggle, tabs, toasts, dialog triggers, menus, slider fill, carousel, table sorting, copy buttons.
dist/vici-icons.svgSVG sprite of all icons (<use href="…#vc-search">), for same-origin use.
dist/tokens.jsonAll resolved token values as JSON, for scripts and other tools.
integrations/Streamlit, Power BI, Python and Tailwind themes generated from the same tokens.
assets/logo/Logo suggestions as SVG in colour, dark and mono.
src/The sources: tokens, CSS per component group, icons, docs pages.

5 · Change the system

The generated files are committed, so nobody needs to build anything to use them. To change Vici itself, edit the sources and rebuild. The only requirement is Node 18 or later; there are no dependencies to install.

node scripts/build.mjs        # rebuild dist/, the docs pages and the exports
npm run check                 # contrast, hexagon rule, fonts, links, logos, exports
npm run palette               # regenerate the colour ramps after editing scripts/palette.mjs

npm run check fails if, for example, a colour pair drops below WCAG AA, a circle sneaks into the CSS, or a generated file is out of date.

Browser support

Vici targets evergreen browsers from 2024 onwards: Chrome, Edge, Firefox and Safari. It relies on CSS cascade layers, custom properties, clip-path, color-mix(), :has(), the <dialog> element and the Popover API. Older browsers still get readable content, but the hexagon shapes and some interactive details may be missing.
