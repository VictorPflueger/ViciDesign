Principles

Five rules the whole system follows

Cells, not circles

Hexagons tessellate: they fit together without gaps. Avatars, radios, badges, spinners and bullets are all cells, and pill shapes become hex capsules.

Deep base, soft light

Merlot #250010 carries text, primary actions and the dark canvas. The pastels carry meaning and atmosphere, never the other way round.

Data first

Tabular figures, a chart palette tested against colour-blindness simulations, and no decoration that competes with the numbers.

Zero friction

One CSS file and one optional script. No build step and no framework lock-in. Copy a snippet into a static page, a prototype or a notebook and it works.

Accessible by default

Every colour pair is checked against WCAG 2.2 AA by the build. Focus is always visible, everything works by keyboard, and motion respects the user's settings.

Quick start

Two lines in your <head>

The stylesheet is and includes the tokens, both themes, every component and icons. The script is optional: it adds the theme toggle, tabs, toasts and a few other behaviours.
