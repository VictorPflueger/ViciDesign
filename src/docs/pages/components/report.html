Report

The document a run ends in. On screen its pages are sheets of paper; printed or saved as PDF they run on A4, and every page carries the prototype's footer: what made it, where to find it, who built it and the page number.

Pages

.vc-report is a column of .vc-report__page sections. The first is the cover, .vc-report__cover: the prototype at the top in .vc-report__brand, the title and one sentence in .vc-report__heading, and the facts of the run at the foot in .vc-report__meta. Each page after it starts a new sheet when printed, and a long page runs on over as many sheets as it needs.

A report names its language with lang and carries data-theme="light", so its sheets stay light in the dark theme too: it ends on paper. The title, .vc-report__title, is the report's one top heading. In a file of its own it is the h1 and every page opens with an h2; inside a page that shows more, it sits one level below the heading around it, as in the example, where the title is an h3 and the pages open with an h4.

Printing and PDF

A report prints alone, whatever else the page shows. Vici.report.print(report) copies it into a container at the end of body marked data-vc-print, which the print styles show instead of the page, opens the browser's print dialog and takes the copy away afterwards. A button with data-vc-report-print="<report id>" does the same without a script of its own. Saving as PDF is the print dialog's own choice, so the button says what the person gets, such as “Save as PDF”.

Someone who presses Ctrl+P instead should get the report too. Vici.report.prepare(report) makes the copy without printing and returns the function that removes it:

let undo = null;
addEventListener('beforeprint', () => { if (report.isConnected) undo = Vici.report.prepare(report); });
addEventListener('afterprint', () => { if (undo) undo(); undo = null; });

The pages run on A4 with margins of 16 mm and 20 mm at the foot. The footer's words live on the report, in its own language, and Vici writes them into the page's margin boxes:

The footer's words, as attributes of the report

Chrome and Edge print margin boxes from version 131, so there the footer carries the page number as “page 2 of 5”. Firefox and Safari have none: there .vc-report__footer, the report's last element, stands fixed at the foot of the page instead, without page numbers, and a browser that repeats fixed elements on every printed page, as Firefox does, prints it on each. Give it the same words, so no browser prints a page without its footer. CSS learns of margin boxes through @supports at-rule(@bottom-left), which Chrome answers from version 148; for versions 131 to 147, Vici.report.prepare() marks the copy data-vc-margin-boxes itself, so those print one footer too.

The notice is for a report that must say something on every page, such as a run that stopped before it was done.

A file of its own

Vici.report.html(report, { title }) returns the report as an HTML file that opens anywhere, offline, and prints with the same footer. The file holds the report's markup with absolute links, its pictures as data, the page's style rules that reach the report and the footer's words. It holds no script and a policy that loads nothing, so it can travel by email. Web fonts stay out: a page under a strict policy cannot read their files, so the file names Inter and falls back to the reader's own fonts. Without a script it cannot mark itself for Chrome 131 to 147, which print its fixed footer beside the margin boxes.

const file = new Blob([Vici.report.html(report)], { type: 'text/html' });
const link = Object.assign(document.createElement('a'), { href: URL.createObjectURL(file), download: 'report.html' });
link.click();
URL.revokeObjectURL(link.href);

What goes in it

  • The cover says what the report is about, when it was made, whether the run was simulated or live and in which language, and which model and setting a live run used.
  • What the AI wrote, suggested or estimated keeps its lilac tag, and every estimate says what it rests on. A simulated company says it is fictional on the cover.
  • Where people can type or upload, the report repeats “Public information only: never enter confidential, personal or otherwise protected data.”
  • A fact about the world shows its source and the date it was read. A run without research says once that the model's knowledge ends at its training cutoff.
  • Nothing needs a pointer: no buttons or fields, no tooltips that hold facts, no closed details, since closed content would not print. A chart has its numbers in a table beside it.
  • The last page ends with the byline, as Byline anywhere sets out.

Check

reportProblems(html) from scripts/lib/report.mjs returns the rules a report breaks: no language, no light theme, a first page that is not a cover, a title that is not the one top heading, a page that opens at the wrong level, a script, a button or field, a closed details, no fixed footer naming Victor Pflüger, no byline on the last page, or a picture without a name. scripts/check-report.mjs proves it on planted mistakes and holds this page to it. scripts/check-report-print.mjs, part of the render checks, prints the example in Chromium and reads the PDF: it fails when a page lacks the footer, the page number or the notice, or prints the footer twice, and it opens the file from Vici.report.html() without a network and fails when it asks for anything or loses the report's look.
