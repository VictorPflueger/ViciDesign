Data display

Components for numbers. Tables align figures on tabular digits, stat cards put a key number up front with its trend, and every series swatch is a small hexagon.

Table

Wrap tables in .vc-table-wrap so they scroll sideways on small screens instead of breaking the layout. While a wrapper scrolls, vici.js makes it focusable and names it after the table's caption, so keyboard users can scroll it too. Right-align numeric columns with .vc-num. Add data-vc-sortable and a .vc-table__sort button in each sortable header, and vici.js sorts the rows and sets aria-sort. Cells can carry a data-value for exact sorting.

Row selection and bulk actions

Put a checkbox in the first cell of each row. The row tint follows the checkbox, so the state is visible and announced. With data-vc-select="#toolbar-id" on the table, vici.js keeps a select-all checkbox in the header (checked, mixed or empty) and a .vc-table-toolbar with the count in sync. The toolbar stays hidden while nothing is selected, and a polite live region announces “2 of 3 selected” (change the wording with data-vc-select-status="{n} von {total} ausgewählt" and data-vc-select-none). Don't rely on aria-selected in a plain table: it only has a meaning in a grid widget.

Chart frame

.vc-chart is a <figure> with a title, a subtitle, the chart, a legend and a source line. Vici doesn't include a charting library. Draw with SVG, D3, Observable Plot or Vega-Lite and use the --vc-data-* tokens for colour. Recommended chart types and the palettes are on Data visualisation.

Anatomy

The frame around a chart you draw yourself. Give the SVG a width and height (the size you drew it at) and wrap it in .vc-chart__plot: the chart keeps that size, so its 11 px labels stay 11 px, and in narrower columns the plot scrolls sideways (with vici.js, it then also becomes focusable, so keyboards can scroll it). Label bars directly where you can, and add a .vc-legend only when there are several series.

Risk matrix

Issues placed by how much they would hurt and how likely they are, both from 1 to 5: impact up, likelihood across. A cell's band follows impact times likelihood: low from 1 to 4, medium from 5 to 9, high from 10 to 15, critical from 16 to 25. Every cell shows its score in the corner and the key names the bands in words, so the bands never rest on colour alone. The bands use the status colours because the data really is good or bad.

Each issue is a numbered hexagon marker in its cell. What is left of an issue after an answer is the same marker, hollow, in its new cell. Selecting a card elsewhere sets aria-current="true" on its marker. The numbers sit in a table one click away, as every chart in Vici offers them.

Where a marker's size tells what the issue puts at stake, as a canvas's expected euros a year do, it takes vc-risk__marker--sm or vc-risk__marker--lg either side of the default: three steps the prototype draws from its own figures, such as thirds of the largest. The key names each size used in words and the table carries the figures, so a size never stands for a number on its own.

Markup

The grid places everything in the order of the markup, so a page under a strict security policy needs no style attribute: row by row from impact 5 at the top, a tick and five cells each, then an empty corner and the five likelihood ticks. Every cell carries data-impact, data-likelihood and data-band, and every marker its own data-impact and data-likelihood, so a test can hold each marker to its cell.

riskMatrixProblems(html) from scripts/lib/risk.mjs returns an empty list when a matrix has its 25 cells, each in the band its score gives and showing that score, every marker in the cell its impact and likelihood name, a key that names all four bands and a table of the numbers. band(score) from the same file gives a score's band.
