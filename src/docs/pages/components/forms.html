Components

Forms

Form controls are native elements with a Vici skin, so validation, autofill, keyboard support and mobile keyboards all work as usual. The hexagon shows up where other systems draw circles: in the radio, the switch knob, the slider thumb and the rating cells.

Field

A field stacks a label, the control, and optional help or error text. Connect the help text with aria-describedby.

Select

A native <select> with a Vici chevron. Use it for six or more options. For fewer, radios or a segmented control show all choices at once.

Combobox

For “type or choose”, combine a text input with a native <datalist>. The browser handles filtering and keyboard selection.

Checkbox

Checkboxes stay square: squares aren't circles. Group them in a <fieldset> with a <legend>. Add data-vc-indeterminate for a mixed parent state.

Data sources

Radio

A hexagon ring with a hexagon dot that grows when selected, drawn with one even-odd clip-path on the native input. Focus shows as an outer hexagon ring.

Inline group

Switch

A hex-capsule track with a hexagon knob. Use a switch for settings that apply immediately. Use a checkbox when the change only takes effect after the user submits the form. Add role="switch".

Slider

A native range input with a hexagon thumb. vici.js fills the track up to the thumb and updates a connected <output>.

Chip

Chips are selectable filters in a hex capsule. Use toggle buttons with aria-pressed and a .vc-chip__check icon, or checkboxes inside a label, where the checkbox itself turns into the check mark. Selected chips get the accent fill and a check, so the state doesn't depend on colour.

Topics

For chips that only display information, use a tag instead.

Rating

Five hexagon cells, filled in honey up to the chosen value. It's a group of native radios, so the arrow keys work. Hovering previews a value.
