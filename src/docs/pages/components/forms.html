Forms

Form controls are native elements with a Vici skin, so validation, autofill, keyboard support and mobile keyboards all work as usual. The hexagon shows up where other systems draw circles: in the radio, the switch knob, the slider thumb and the rating cells.

Field

A field stacks a label, the control, and optional help or error text. Connect the help text with aria-describedby.

Select

A native <select> with a Vici chevron. Use it for six or more options. For fewer, radios or a segmented control show all choices at once.

Combobox

For “type or choose”, combine a text input with a native <datalist>. The browser handles filtering and keyboard selection.

Checkbox

Checkboxes stay square: squares aren't circles. Group them in a <fieldset> with a <legend>. Add data-vc-indeterminate for a mixed parent state.

Switch

A hex-capsule track with a hexagon knob. Use a switch for settings that apply immediately. Use a checkbox when the change only takes effect after the user submits the form. Add role="switch".

Slider

A native range input with a hexagon thumb. vici.js fills the track up to the thumb and updates a connected <output>. An output with data-vc-currency="EUR" shows the value as money in the language of the page around it, such as “€0.50” or “0,50 €”.

Chip

Chips are selectable filters in a hex capsule. Use toggle buttons with aria-pressed and a .vc-chip__check icon, or checkboxes inside a label, where the checkbox itself turns into the check mark. Selected chips get the accent fill and a check, so the state doesn't depend on colour.

Topics

For chips that only display information, use a tag instead.

Rating

Five hexagon cells, filled in honey up to the chosen value. It's a group of native radios, so the arrow keys work. Hovering previews a value.

Drop zone

Where people drop files or choose them. The zone is the <label> of a real file input, which stays in the tab order but out of sight, so a click, the keyboard and a screen reader all open the browser's file dialog. accept names the kinds of file it takes, and the notice under it says what may be uploaded. While files are dragged over it, the edge turns solid and the zone takes the soft accent.

vici.js sends dropped and chosen files to the page as one cancelable vc:files event on the zone, with detail.files, and clears the input so the same file can come again. A page that checks files itself calls preventDefault() and lists them; otherwise Vici lists each file's name and size with a remove button (data-vc-dropzone-remove="Entfernen: {name}" changes the wording). While a zone is on the page, a file dropped beside it is caught instead of being opened by the browser, which would leave the page and lose its work.

Each file is a row with its name, its kind and size, any tags and a remove button that names the file. A refused file says why in words, with data-state="refused" and a .vc-dropzone__error; data-state="warning" does the same for a file that may go ahead.
