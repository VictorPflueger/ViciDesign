Components

Actions

Buttons start things, links go places. Buttons are calm rectangles, and icon buttons are hexagon cells. A view should have one primary action.

Button

Use <button> for actions and <a class="vc-button"> only when it navigates. The primary button is filled with the base colour. In dark mode it turns into pastel blush with merlot text.

Sizes and icons

States

A toggle button keeps its state in aria-pressed. With vici.js loaded, clicking flips it. A busy button gets aria-busy="true" and a spinner; keep its label meaningful (“Saving…”).

Icon button

An icon button is a hexagon cell. The element itself stays unclipped: ::before paints the cell and ::after draws the hexagonal focus ring. Always give it an aria-label.

Variants: default (ghost), --soft, --solid, --outline, --floating. Sizes: --sm, --lg. Pair icon-only buttons with a tooltip.

Link

Links in running text are underlined in merlot and need no class. Use .vc-link for standalone links such as “Read more”, and the external icon when a link leaves the site.

Segmented control

A segmented control picks one of two to five options that change a view. It's a radio group, so it needs no script and works with the arrow keys.

Use tabs instead when each option shows different content, and a select when there are more than five options.
