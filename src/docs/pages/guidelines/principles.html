Guidelines

Concept & principles

Vici is a small system with a strong signature. It has to make a quick prototype look deliberate, keep a data dashboard readable and give a personal website a recognisable face, all without slowing anyone down.

The idea: a honeycomb

A honeycomb is nature's most efficient structure. Identical cells tessellate without gaps, carry load in every direction and can grow in any direction. That is a good description of a design system too: a few precise parts that fit together and scale.

Vici takes this literally. The hexagon is its only signature shape. Wherever an interface would normally use a circle (an avatar, a radio button, a status dot, a loading spinner, a list bullet), Vici uses a flat-top hexagon. Wherever it would use a pill, it uses a hex capsule with pointed ends. Everything else stays a calm rectangle with small radii, so the cells stand out.

The palette: one deep base, many soft lights

The base colour, merlot #250010, is so dark it reads almost as black, with a warm wine undertone. It writes the text, fills the primary buttons and, in dark mode, becomes the canvas itself. Its own ramp lightens into blush pinks, and seven more pastel families sit around it: coral, apricot, honey, sage, teal, fjord and lilac. Every family is light and soft in its pastel steps and deep enough at its dark end to carry readable text.

The split of responsibilities is the core of the colour system. The base colour gives contrast and seriousness. The pastels give warmth, atmosphere and meaning: lilac marks AI, sage marks success and honey marks attention. See Colour.

Personality

Precise

Exact geometry, a strict 4 px grid and tabular numbers. Nothing is approximately aligned.

Warm

Wine and pastels instead of cold blue-grey. Linen paper instead of pure white canvases.

Data-literate

Built for dashboards and AI demos: chart colours, KPI cards, dense tables and calm status colours.

Principles

1 · Cells, not circles

If it would be round, make it a hexagon. If it would be a pill, make it a hex capsule. Never mix the two: one circle in a Vici interface looks like a mistake.

2 · Deep base, soft light

Use merlot for ink, primary actions and the dark canvas. Use pastels for surfaces that carry meaning, for selection and for illustration. Never set body text in a pastel on a light background.

3 · Data first

Decoration must never compete with numbers. Use tabular figures in every column of numbers, keep charts to six categorical colours, and label data directly where you can.

4 · Zero friction

Vici has to be faster than not using it. Plain HTML is styled, components are single classes, and no build step stands between an idea and a working page.

5 · Accessible by default

Contrast is checked by the build, focus is always visible (as a hexagon ring on hexagon controls), every interactive part is reachable by keyboard, and animations respect reduced-motion settings.

Writing in Vici

Interface text follows the same restraint as the visuals:

  • Write labels as verbs for actions (Save changes, Export CSV) and nouns for places (Settings, Reports).
  • Use sentence case everywhere: buttons, headings, menu items.
  • Say what happened and what to do next in errors: “The file is larger than 20 MB. Choose a smaller file or compress it.”
  • Mark AI-generated content honestly, with the AI feature tone, so readers know what a model wrote.
