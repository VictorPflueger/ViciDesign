Guidelines

Layout & spacing

Everything sits on a 4 px grid. A handful of layout primitives (stack, cluster, grid, split) cover almost every arrangement, so a page is built from intent rather than from margins.

Spacing scale

A token's number is its multiple of 4 px: --vc-space-4 is 16 px. Small steps separate related things, large steps separate sections.

RangeUse
1–2Icon to label, inside chips and badges
3–4Between controls in a group, padding of compact components
5–6Card padding, gaps in grids
8–12Between groups within a section
16–32Between page sections

Grid: responsive columns

.vc-grid fits as many columns as there is room for, never narrower than --vc-grid-min. .vc-grid--2/3/4 fix the number of columns and collapse on small screens. .vc-grid-12 with .vc-span-1…12 gives a classic 12-column grid from 768 px.

Split: sidebar and main

.vc-split puts a side pane (--vc-split-side, default 18rem) next to a fluid main pane and stacks them when the main pane would get too narrow. No media query needed.

Side
Main content takes the remaining width and wraps below the side pane on narrow screens.

Density

Components default to a comfortable density: 40 px controls and 16–20 px card padding. For data-heavy screens, use the small control size (--sm modifiers, 32 px), .vc-table--compact and a --vc-space-3 grid gap. Don't go below 32 px for anything clickable on a touch screen. 44 px is the comfortable minimum for touch targets.
