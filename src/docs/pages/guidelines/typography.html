Guidelines

Typography

Three free, open-source variable fonts with clear jobs: a characterful grotesque for headlines, a highly legible sans for everything you read and click, and a monospace for code and identifiers. All three ship with Vici under the SIL Open Font License 1.1.

Typefaces

Display

Aa Gg

Bricolage Grotesque

Headlines H1–H3, display numbers, the wordmark. Its optical-size axis adds ink traps and tighter spacing at large sizes, which gives headlines a crafted, personal look.

wght 200–800opsz 12–96

Text & UI

Aa Gg

Inter

Body copy, labels, buttons, tables, H4–H6. Built for screens, with tabular figures, a large x-height and clear shapes that keep small UI text readable.

wght 100–900opsz 14–32italic

Code & data

Aa 0O

JetBrains Mono

Code, IDs, keyboard keys, hex values. Distinguishes 0/O and 1/l/I at a glance, which matters for data work.

wght 100–800

The fonts load from assets/fonts/ next to the stylesheet. Latin and Latin Extended subsets are split by unicode-range, so a German page downloads one file per family (umlauts and ß are part of the base Latin subset). To swap a family, override --vc-font-display, --vc-font-text or --vc-font-mono.

Type scale

Sizes from 2xs to 2xl are fixed. Headline sizes from 3xl upwards are fluid: they grow with the viewport between the two values given, so a hero never overflows on a phone.

Text styles

The elements h1–h6 are styled without classes. The same styles also exist as classes (.vc-h1 … .vc-h6, .vc-display, .vc-lead, .vc-eyebrow, .vc-caption), so the visual size can differ from the document outline. The specimen below uses the classes.

Numbers

Numbers in tables, KPIs and anything that changes live use tabular figures. Every digit is equally wide, so columns line up and values don't jitter while they update. Vici's tables and stat cards switch them on automatically; elsewhere add .vc-tabular.

  • Right-align numbers in tables, and align the column heading with them.
  • Use the same number of decimals in a column.
  • Use a thin space or the locale's separator for thousands. German pages use 1.234,5, English pages 1,234.5.

Line length and rhythm

  • Keep reading text between 55 and 75 characters per line. .vc-prose and --vc-container-prose (68ch) do this for you.
  • Body line height is 1.5, long-form prose 1.65, headlines 1.02–1.3. Larger text needs less leading.
  • Headlines get tighter letter-spacing as they grow (--vc-tracking-display). All-caps labels get wider spacing (--vc-tracking-caps).
  • Headings use text-wrap: balance and paragraphs text-wrap: pretty, so lines break evenly without manual line breaks.

Typesetting German

For pages in German, a few details make the difference between translated and professionally set:

  • Set lang="de" on <html>. Screen readers then pronounce the text correctly, and hyphens: auto can break long compounds such as Datenschutzgrundverordnung.
  • Use German quotation marks „…“ and ‚…‘, real dashes (– for ranges and parenthetical asides), and a non-breaking space between number and unit: 20&nbsp;%, 5&nbsp;GB.
  • The fonts include ß and the capital ẞ for all-caps labels.
Do

Quarterly review

Use Bricolage for short, large headlines, and keep them to a line or two.

Don't

Small body text set in the display face is harder to read at UI sizes.

Don't set body text, labels or table cells in the display face. That's Inter's job.
