Guidelines

Motion

Motion in Vici explains what changed. It never decorates. It is quick enough that nobody waits for it, soft enough to feel calm, and it switches itself off when the operating system asks for reduced motion.

Principles

Quick

Most transitions finish in 130–210 ms. Only dialogs and drawers take longer.

Directional

Things enter fast and land softly, and leave the other way round. Elements move from where they came from.

Optional

Every interaction works without animation. Reduced motion turns it off, except for the spinner's slow sweep.

Reduced motion

When the operating system asks for reduced motion (prefers-reduced-motion: reduce), Vici cuts every transition and animation to a single frame. The one exception is the spinner, which slows to a 2.4 s sweep, because without it nobody can tell that work is in progress. Do the same in your own CSS:

@media (prefers-reduced-motion: reduce) {
  .my-hero-animation { animation: none; }
}
