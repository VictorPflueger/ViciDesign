Integrations

Prototypes don't all live in HTML. The build turns the tokens into ready-made themes for the tools around it, so a Streamlit app, a Power BI report and a matplotlib chart can share one palette. Every file in integrations/ is generated, so never edit it by hand.

Streamlit

Copy integrations/streamlit/config.toml (or config-dark.toml) to .streamlit/config.toml in your app. It sets the primary colour, the backgrounds and the text colour from the light or dark theme.

[theme]
base = "light"
primaryColor = "#250010"
backgroundColor = "#fbf7f5"
secondaryBackgroundColor = "#f3ebe7"
textColor = "#250010"
font = "sans serif"

For custom HTML inside Streamlit (st.html or components), link dist/vici.min.css from the CDN and use the classes as usual.

Power BI

Import integrations/powerbi/vici-light.json via View → Themes → Browse for themes. The theme sets the eight data colours in the order on Data visualisation, the good/neutral/bad status colours, the sequential scale and the table accent. Text uses Segoe UI, because the Power BI service cannot load web fonts.

Python: matplotlib and plotly

integrations/python/vici_palette.py is a single file with no required dependencies. Drop it next to your notebook.

from vici_palette import CATEGORICAL, SEQUENTIAL, use_matplotlib, plotly_template

use_matplotlib()                          # Vici colours, grid and hexagon markers
fig.update_layout(template=plotly_template("dark"))
ax.bar(labels, values, color=CATEGORICAL[0])

It also exposes COLORS (every ramp), LIGHT and DARK (every semantic token), and the categorical, sequential and diverging lists for both themes.

Tailwind CSS v4

integrations/tailwind/vici-theme.css contains an @theme block with every colour ramp, the three font stacks, radii, easings, breakpoints and the 4 px spacing unit.

@import "tailwindcss";
@import "./vici-theme.css";

/* → bg-merlot-950 text-neutral-50 font-display rounded-md ease-standard … */

Load the fonts by also linking dist/vici-tokens.css, or the full dist/vici.css if you want the components too.

Figma and other design tools

src/tokens/tokens.json follows the structure of the Design Tokens Community Group format ($value, $type, {references}), which token plugins such as Tokens Studio can import. The light and dark themes are separate sets under theme.light and theme.dark. For scripts that just need the values, dist/tokens.json has everything resolved to plain hex codes and lengths.

Plain JSON

const tokens = await (await fetch('https://cdn.jsdelivr.net/gh/VictorPflueger/ViciDesign@main/dist/tokens.json')).json();
tokens.light.accent      // "#250010"
tokens.dark['data-2']    // first-class chart colours, per theme
tokens.color.lilac['200']
