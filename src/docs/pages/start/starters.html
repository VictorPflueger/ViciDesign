How to use a starter

  1. Copy the HTML file into your project.
  2. Point the <link> and <script> tags at your copy of dist/ or at the CDN (see Getting started).
  3. Replace the sample content. Every section is self-contained, so you can delete whole blocks without breaking the layout.

The starters use only documented classes and a few inline style attributes for page-specific spacing. Nothing in them is required by the system.
