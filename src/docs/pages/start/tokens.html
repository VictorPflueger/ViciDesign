Token reference

Every value in Vici is a design token. This page is generated from src/tokens/tokens.json on every build, so it always matches the stylesheet. Theme tokens list the primitive they point to; switching the theme only changes those pointers.

Naming

PatternExampleKind
--vc-{family}-{step}--vc-merlot-950, --vc-sage-200Primitive colour (same in both themes)
--vc-{role}--vc-surface, --vc-text-muted, --vc-danger-bgSemantic colour (changes with the theme)
--vc-space-{n}--vc-space-4 = 16pxSpacing, n × 4px
--vc-font-size-{size}--vc-font-size-smType scale
--vc-cell-{size}--vc-cell-lgHexagon height
--vc-radius-{size}--vc-radius-mdCorner radius for rectangles
--vc-shadow-{size}--vc-shadow-lgElevation (tinted per theme)
--vc-duration-*, --vc-ease-*--vc-ease-enterMotion
